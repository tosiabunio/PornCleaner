Installation guide

A little less history.
Ready in a few steps.

Your extension is already built. Follow these steps in Chrome on Windows, macOS, or Linux.

Cleaning starts as soon as you install.

PornCleaner automatically deletes existing and future history for {{DOMAIN_COUNT}} listed domains. Deletion cannot be undone and may sync to your other Chrome devices. You can pause cleaning and add exceptions after installation.

  1. Unzip and keep the folder

    On Windows, right-click the download and choose Extract All. On macOS, double-click the ZIP. On Linux, choose Extract in your file manager.

    Move the extracted PornCleaner folder somewhere permanent, such as Documents, before continuing.

    Keep this folder in place after installation. Chrome loads the extension from it.

  2. Open Chrome’s extensions page

    Open Google Chrome. Type this address into the address bar and press Enter:

    chrome://extensions

    Use Chrome’s address bar, rather than a search box on a webpage.

  3. Enable Developer mode

    Turn on Developer mode at the top right. Then click Load unpacked.

    Developer mode →Load unpacked

    Chrome requires this setting when installing from a ZIP download.

  4. Select the Chrome folder

    Open your extracted PornCleaner folder, select the folder named Chrome, and confirm.

    PornCleaner/Chrome/ ← select this folder

    The Chrome folder contains manifest.json. Select the folder itself, not the ZIP or an individual file.

Installed. Cleaning is on.

The PornCleaner management page opens automatically. Click Chrome’s puzzle-piece icon and pin PornCleaner for quick access to Pause cleaning.

Use “Your exceptions” to keep a domain’s history. “Pause & scan” lets you review a manual cleanup.

“Manifest file is missing” or the folder will not load

Make sure you extracted the ZIP, then choose PornCleaner → Chrome. That folder should contain manifest.json and worker.js. If Developer mode or Load unpacked is unavailable, your organization may manage Chrome; ask its administrator.

How do I update without losing my settings?

Updates to this ZIP installation are manual. Download and extract the new version. Replace the files inside the original Chrome folder with the new Chrome folder’s files, keeping the original folder location. Go to chrome://extensions and click Reload on PornCleaner. Your saved pause setting and exceptions are retained. Export your settings from PornCleaner first if you want a backup.

How do I pause or remove it?

Click PornCleaner’s toolbar icon, then Pause cleaning. To uninstall, open chrome://extensions, find PornCleaner, and click Remove. Previously deleted history cannot be restored by the extension.

Which data does it clean?

Matching and deletion happen locally using the bundled domain list. Unlisted domains, cookies, bookmarks, downloaded files, open tabs, and Google account search activity are outside this cleanup. Chrome history sync may carry deletions to your other devices.
